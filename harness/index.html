Why this exists

Most “agent demos” die the week after the pitch. Harness is the opposite bet: one maintained runtime that custom desks and internal tools can stand on.

One-off scripts

Every project reinvented the agent

New Python glue, new tool schemas, new crash modes. Cost tracking and session recovery were optional extras people forgot until production.

Fragile providers

One API key failure stops the job

Real work needs a router that can fall through providers, keep a session, and resume instead of starting over when a call fails.

Unsupervised tools

Agents that write anywhere are a liability

Shell, git, and file edits need allowlists, plan mode, and recoverable runs — not “trust me” on a customer machine.

What Harness does

A terminal-native coding agent with the pieces operators actually need after the demo.
