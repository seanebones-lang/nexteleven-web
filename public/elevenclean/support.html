Instructions for ElevenClean 1.2.0 · Update in preparation; your current App Store version may differ.

Start with one toolchain

  1. Open Settings and choose the folder you want to scan, usually your home folder, using the standard macOS folder picker.
  2. Open Toolchains, choose the tools you use, then scan. Scanning does not remove files.
  3. In Review files, inspect exact paths and Details. Close the owning development tools before cleanup. Removing caches can require downloads and rebuilds.
  4. Review the complete selected list, then move only disposable data to Trash. Larger selections need an additional acknowledgement.
Why is a scan empty or incomplete?

Open Scan coverage to see checked, missing, protected, unavailable and unselected roots. This is a root-access report, not a full-disk audit or proof that every file was readable. Some folders may not be accessible with your grant. Personal-file review is off by default, and its age, size, hidden-file and result filters can omit content. No results does not prove the whole computer is clean.

How do protected folders work?

Add active projects or irreplaceable folders in Settings. Their contents are excluded, and a cleanup parent containing protected data is also kept. Changing protection clears stale scan selections. Protection follows the saved path, so update it if a folder is moved or renamed. Built-in system and credential exclusions continue to apply.

Why did a file get skipped?

The file may have changed, disappeared or been replaced since the scan. It may be protected, aliased, unavailable or part of a running app. Open Cleanup details for the actual outcome, then rescan before reviewing it again. Do not broaden access merely to force a failed cleanup.

How do I restore something?

Open Cleanup details and use Show in Trash, or open Finder's Trash. Select the item and use Put Back when Finder offers it. Restore before emptying Trash. ElevenClean does not empty Trash or guarantee recovery after you do.

Why didn't available storage increase?

Moving files to Trash usually keeps their disk blocks on the same volume. The receipt separates logical bytes moved from the observed change in macOS-reported available capacity. Use Recheck storage later. APFS sharing, purgeable storage, snapshots and other activity can change the number independently of cleanup.

What should I keep?

Keep anything you cannot confidently rebuild or download again. DerivedData requires review; recent device symbols are not preselected. A Maven repository may contain locally installed artifacts unavailable elsewhere. ElevenClean's developer targets do not include source repositories, simulator devices or Xcode archives. Review personal files and suggested support data individually; a matching name alone does not establish ownership.

What about Docker?

ElevenClean offers a usage preview when the Docker CLI is available. Open Docker Desktop for its own cleanup controls. There is no Docker prune action in the 1.2.0 app UI.

How do I reopen the window?

Closing the sole window quits this single-window app. Relaunch ElevenClean to open Overview. Preferences and the latest receipt persist. Window → Main Window is also available while the app is running.
